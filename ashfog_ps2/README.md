# ASHFOG для PS2 (порт, этап 1)

## Сборка
1. Docker Desktop + `build_ps2.bat` → получишь `ashfog.elf`.
2. Тест: PCSX2 → System → Boot ELF → ashfog.elf.
3. На консоль: скопируй `ashfog.elf` на FAT32-флешку, запусти через uLaunchELF / OPL (нужна прошитая PS2).

## Управление (DualShock 2)
Левый стик или крестовина: ход/поворот (танковое, как в оригинале) | Square или R1: бег | Cross: действие (дверь/предмет) | Triangle: аптечка.
HUD: красная/зелёная полоса - здоровье, красные квадраты - аптечки, жёлтые - ключи.

## Что есть
Все 3 уровня (больница → город → кладбище) из тех же ASCII-карт, коллизии, двери и ключи, предметы, враги w/z/N/Y (погоня и урон), камера за спиной, туман, GS Z-buffer.

## Чего пока нет
Текстуры, звук/музыка, текст (записки, подсказки), оружие и бой, паника, фонарь, захват, анимации. Всё это следующие этапы.

## Структура
`tools/export_levels.py` - выгрузка карт из ../ashfog/levels в `src/levels_data.h` (запускать после правки карт).
`src/game.c` - логика. `src/render.c` - геометрия+туман, `src/main_ps2.c` - железо.
`src/test_render.c` - проверка кадра на ПК без PS2 (`build_host_test.bat`).

## Сборка без Docker (GitHub)
Создай репозиторий, залей содержимое папки (включая скрытую .github), открой вкладку Actions -> build-ps2 -> готовый run -> Artifacts -> ashfog-elf (zip с ashfog.elf).
